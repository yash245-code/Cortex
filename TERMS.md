## 3. Privacy, Telemetry & Local Execution

BUIMB Research believes developers deserve full autonomy and privacy:
- **Local Execution**: All editor core features, file indexing, Monaco language services, and `node-pty` terminal instances execute strictly on your local machine.
- **Zero Hidden Telemetry**: BUIMB Research does not collect, track, or transmit your private codebase, file contents, or shell activities.
- **Local Storage**: User preferences, recent workspaces, and session caches reside locally on your device in `%APPDATA%/Bodhi`.

---

## 4. Artificial Intelligence (AI) Features & Third-Party APIs

- **User-Provided API Keys**: Bodhi provides optional AI features (such as inline code completions, ghost-text suggestions, and conversational chat) that communicate directly with third-party LLM providers (e.g., Google Gemini, OpenAI, Anthropic). You must provide your own API key to activate these features.
- **Direct Client-to-Provider Communication**: API queries and file context snippets are sent directly from your client machine to your chosen model provider. BUIMB Research operates no middleman proxy or logging servers for your AI requests.
- **Reviewing Output**: Code and answers generated by AI models may be imperfect or unverified. You remain responsible for inspecting, testing, and verifying all generated code before deploying to production.
