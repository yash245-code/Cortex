# Implementation Plan: Cortex Code Editor

Build **Cortex**, a modern, lightweight, performant, and extensible desktop code editor built with Electron, `electron-vite`, TypeScript, React, Monaco Editor, `node-pty` terminal integration, and `chokidar` file watching with strict process isolation.

## User Review Required

> [!IMPORTANT]
> - **Native Module Compilation:** On Windows, `node-pty` is a C++ native addon. We will configure `electron-builder` / `electron-vite` with native module externalization so that `node-pty` operates seamlessly in the Electron main process, with a robust fallback shell runner if node-pty build environment lacks VS build tools.
> - **Process Isolation:** The renderer strictly communicates through the context bridge (`window.cortexAPI`) without raw Node.js APIs exposed.

## Implementation Steps

### Step 1: Initialize Project & Tooling
- Configure `package.json` with dependencies:
  - Electron runtime: `electron`, `electron-vite`, `electron-builder`
  - Core UI: `react`, `react-dom`, `@types/react`, `@types/react-dom`
  - Editor & Terminal: `@monaco-editor/react`, `monaco-editor`, `xterm`, `xterm-addon-fit`, `node-pty`
  - File Watching & Utils: `chokidar`, `lucide-react`, `zustand`, `clsx`, `tailwind-merge`
  - Styling: `tailwindcss`, `postcss`, `autoprefixer`
  - TypeScript & Linters: `typescript`, `@types/node`
- Setup `electron.vite.config.ts` ensuring `node-pty` and `chokidar` are externalized in the main bundle.
- Setup `tsconfig.json`, `tailwind.config.ts`, and `postcss.config.js`.

### Step 2: Shared Types & IPC Channels (`src/shared/`)
- Define strict types:
  - `FileNode`: `id`, `name`, `path`, `type` ('file' | 'directory'), `children?`, `extension?`
  - `Tab`: `id`, `path`, `name`, `content`, `savedContent`, `isDirty`, `language`
  - `TerminalDataPayload`, `TerminalResizePayload`
  - `IPC_CHANNELS` constants mapping all message channels.

### Step 3: Main Process & Background Services (`src/main/`)
- **`fileService.ts`**:
  - `openFileDialog()`, `openDirectoryDialog()`
  - `readDirectory(dirPath)`: recursive directory traversal ignoring `.git`, `node_modules`, `dist`
  - `readFile(filePath)`, `writeFile(filePath, content)`
  - `createFile(path)`, `createDirectory(path)`, `renamePath(oldPath, newPath)`, `deletePath(path)`
  - `startWatcher(dirPath, onEvent)`, `stopWatcher()` via Chokidar
- **`terminalService.ts`**:
  - Initialize PTY instance (`powershell.exe` on Windows or user `$SHELL` / `bash`) with default `cwd`.
  - Stream `onData` to IPC channel, forward `write(data)` and `resize(cols, rows)`.
  - Process cleanup on window close or exit.
- **`ipcHandlers.ts`**:
  - Register handlers for dialogs, file operations, watcher subscriptions, terminal streaming, and frameless window actions (minimize, maximize, close, isMaximized).
- **`index.ts`**:
  - Create frameless `BrowserWindow` with custom titlebar config (`titleBarStyle: 'hidden'`, `frame: false`).

### Step 4: Preload & Secure Context Bridge (`src/preload/`)
- Expose `window.cortexAPI` with strictly typed async/event methods.
- Provide cleanup mechanisms for listeners (file change events, terminal data).

### Step 5: State Management (`src/renderer/src/store/`)
- **`useWorkspaceStore`**:
  - State: `rootPath`, `rootNode`, `expandedPaths`, `selectedPath`, `isLoading`
  - Actions: `openFolder()`, `openFile()`, `refreshTree()`, `toggleExpand()`, `createFile()`, `createFolder()`, `deleteItem()`, `renameItem()`
- **`useEditorStore`**:
  - State: `tabs`, `activeTabId`, `settings` (fontSize, minimap, wordWrap)
  - Actions: `openTab()`, `closeTab()`, `setActiveTab()`, `updateTabContent()`, `saveActiveTab()`, `saveAllTabs()`, `updateSettings()`

### Step 6: UI Components & Layout (`src/renderer/src/components/`)
- **`TitleBar.tsx`**: Cortex logo & branding, current active file breadcrumb, maximize/minimize/close buttons.
- **`Sidebar.tsx` & `FileTree.tsx`**: Modern file tree with Lucide icons (file type specific badges), hover actions (new file, new folder, refresh), inline rename input, right-click context menu / action bar.
- **`TabBar.tsx`**: Chrome/VSCode-style sleek tabs with dirty indicators, close button, middle-click close, active tab glow.
- **`CodeEditor.tsx`**: Monaco editor with dark theme (`vs-dark`), language detection from file extensions, auto-layout, keyboard shortcut bindings (`Ctrl+S`, `Ctrl+W`).
- **`TerminalPanel.tsx`**: Collapsible bottom dock, Xterm.js terminal with FitAddon, clear button, restart shell button.
- **`StatusBar.tsx`**: Bottom status bar showing line/column, encoding (UTF-8), language, terminal toggle toggle button.
- Resizable split-pane system for Sidebar and Terminal.

## Verification Plan

### Automated Build Verification
1. `npm run build` / `npx electron-vite build` to verify TypeScript compile across main, preload, and renderer.
2. Run linters and typechecks (`tsc --noEmit`).

### Functional Verification
1. Launch app with `npm run dev`.
2. Test opening directory and browsing file tree.
3. Test creating a new file, editing it in Monaco Editor, observing dirty state `●`, and saving with `Ctrl+S`.
4. Test integrated terminal with interactive commands (e.g. `dir`, `echo test`, `node -v`).
5. Test resizing sidebar and terminal panels.
6. Verify live file watching when external changes occur.
