Here are 5 major, high-impact features perfectly suited for a sprint before 12:00 AM. Each adds serious capability and polish to Cortex without getting bogged down in overly complex external dependencies:

1. 🔍 Quick Open & Command Palette (Ctrl+P / Ctrl+Shift+P)
What it does:
Ctrl+P (Fuzzy File Finder): Opens a sleek modal with instant fuzzy search across all files in the current workspace. Pressing Enter instantly opens that tab.
Ctrl+Shift+P (Command Palette): Type commands (e.g., > Toggle Terminal, > Save All, > Format Document, > Split Editor, > Close All Tabs) with keyboard navigation.
Why it's major: This is the #1 feature that makes a code editor feel like a professional tool rather than a basic text pad.
Technical Effort: ~1.5 hours (Zustand state + modal component + fuse/fuzzy matching over the workspace tree).
2. 🔎 Full-Text Workspace Search & Replace (Ctrl+Shift+F)
What it does:
Adds a Search tab to the Activity Bar.
Searches regex or text strings across every file in the opened project via a fast backend IPC search (ripgrep/Node stream).
Lists results grouped by file with line numbers and preview snippets.
Clicking any search result opens the file and jumps directly to that line & column in Monaco.
Includes batch "Replace All" functionality.
Why it's major: Essential for navigating large real-world codebases and refactoring code across multiple files.
Technical Effort: ~1.5 – 2 hours (Backend IPC search service + sidebar search panel UI + Monaco line jumping).
3. 🖥️ Multi-Terminal Manager & Shell Switcher
What it does:
Upgrades the single terminal dock into a multi-session terminal system.
Add multiple terminal tabs with a + button (e.g. 1: powershell, 2: cmd, 3: bash / dev server).
Switch between running terminal sessions without losing output or killing background servers.
Shell selector to spawn PowerShell, Command Prompt, Git Bash, or WSL.
Split terminal horizontally or vertically inside the dock.
Why it's major: Developers frequently need one terminal for npm run dev, another for git, and another for CLI tasks simultaneously.
Technical Effort: ~1.5 hours (Multi-terminal map in terminalService.ts + terminal tab bar in TerminalPanel.tsx).
4. 🔀 Split Editor View (Side-by-Side Dual Panes)
What it does:
Split the main editing workspace horizontally or vertically (Left/Right or Top/Bottom).
Compare two files side-by-side or edit styles and markup at the same time.
Drag or send tabs between Pane 1 and Pane 2, with independent Monaco editor instances and synchronized status bar focus.
Why it's major: Transforms Cortex from a single-buffer view into a true multi-tasking workspace.
Technical Effort: ~1.5 – 2 hours (Update useEditorStore with pane state + dual Monaco wrapper layout).
5. 📝 Real-Time Markdown Live Preview (Ctrl+Shift+V / Split Preview)
What it does:
When opening any .md file, an icon appears in the tab bar to toggle Live Markdown Preview.
Renders GitHub-flavored Markdown in a live side-by-side pane as you type: code blocks with copy buttons, tables, badges, and styled task lists matching the #5DD62C green theme.
Why it's major: Instant visual feedback for documentation, README editing, and notes without leaving the editor.
Technical Effort: ~1 hour (Markdown rendering pipeline with syntax styling + synchronized scroll).
🌟 Bonus Alternate: ⚙️ Settings Modal & Editor Config Drawer (Ctrl+,)
Live customizable editor settings: Font Size slider, Font Family picker, Tab Size (2 vs 4), Word Wrap toggle, Minimap toggle, Line numbers mode, and Auto-save intervals—persisted to local configuration.
